# Everflow Free Workbooks

Everflow 免费做题本与学习资源公开分享页。

## 功能
- 顶部致谢 / 团队说明
- 免费做题本资源卡片
- 一键打开资源
- 一键复制资源链接
- 响应式移动端布局
- GitHub Pages 自动部署

## 修改资源
编辑 `app.js` 中的 `resources` 数组，把 `url` 替换为正式资源链接即可。

## 修改致谢
编辑 `index.html` 的“特别鸣谢”文字，或维护 `app.js` 中的 `contributors` 数据。

## GitHub Pages
仓库上传后，Actions 工作流会自动部署静态页面。首次使用时，如 GitHub 要求，请在 `Settings → Pages → Source` 选择 `GitHub Actions`。
