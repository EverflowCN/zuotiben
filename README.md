# 彼时流年若水 · Everflow 做题本

免费的浏览器本地试卷、做题本及错题整理工具。支持 A4/A3、题目编辑、LaTeX 数学公式、选项排版、浏览器分页与 PDF 导出。

## 使用方式

访问网站的「做题本」入口，或在本地静态服务器中打开 `paper/index.html`。可以把 AI 转录得到的 Markdown 直接粘贴导入，也可以导入自有的 JSON、Markdown 或 `.everflow` 项目文件。

正式编辑器包含本机多试卷目录、跨试卷选题图谱、答案与解析显示开关、IndexedDB 历史存档；原有 localStorage 单份草稿继续兼容。网站的打卡页为 `/checkin/`，仅将日期和随记存入当前浏览器。

**存储说明：** 本地存储不是云端同步。更换设备、清除浏览器数据、隐私模式或站点存储超额可能导致历史丢失，请定期通过「保存项目」导出 `.everflow` 备份。跨域或不同网站的浏览器存储不互通。

**导出说明：** 当前直接下载 PDF 基于预览 DOM 逐页转换为图像型 PDF；打印为独立操作。复杂长题不能安全分页时会阻止导出，并在编辑器定位对应题目。当前模板是网页版排版实现，不等于直接执行用户的 XeLaTeX `.cls`。
