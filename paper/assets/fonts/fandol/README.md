# Vendored Fandol webfonts

These webfont files are local WOFF2 conversions of the exact Fandol OTF files previously loaded by the editor from jsDelivr.

Upstream: Yixf-Self/fandol-fonts
Pinned source commit: b93300821373d3092e378e57ae22ecb8e9082c62
Included families: FandolSong Regular/Bold and FandolHei Regular/Bold
License: GNU GPL v3 with the font embedding exception included at the end of COPYING.
Purpose: deterministic local rendering for the paper/editor preview with no runtime font CDN dependency.
