# Paper Studio · 对齐 Everflow 母版的验收要求

更新时间：2026-10-09。状态：界面 v2 已提交；排版与母版一致性尚未验收。

## 一、事实和边界

- 现有 `/paper/` 不是浏览器 HTML/CSS 直接输出 PDF：编辑页通过 Typst WASM + MiTeX 公式转换生成 PDF 和 SVG 预览。
- 现有 `/paper/editor/everflow-template.txt`、`typst-template.js` 是客户端可访问的前端资源，**不具备私有模板的保密属性**。
- 用户原始 Everflow XeLaTeX `.cls` **不能**因为 Typst 模板同名或参数相近，就认定转换已一致。
- v2 修改的是交互入口、布局、可读性和初始体验；PDF 引擎及私有模板隔离**尚未替换**。不要写“100% 还原”“与 TeXPage 完全一致”。

## 三、回归测试样本

必须以用户确定的 **“数学二 85 套 ExamA4 修订版”** 和 Everflow 固定母版作为权威标准；如果无法取得对应 PDF+TeX 源码，标注为“尚未校准”，不允许宣称一致。

- 样本 A：A4 中/短选择题（4/2/1 栏）和题目换页。
- 样本 B：带矩阵、二重积分、极限、复杂上下标的填空题。
- 样本 C：题干带图、表格、`lstlisting` 程序段、`bbox` 空框的综合题。
- 样本 D：Book standard 与 PadL/PadP 一题一页。
- 样本 E：A3 双栏 / 混排以及每套试卷偶数页补白。
- 样本 F：封面、目录、前言、打印说明、二维码、水印、左右页眉页脚。

对每个样本保留「原 XeLaTeX 版 PDF」「新引擎版 PDF」「相同页数和分页位置的对照记录」「截图差分」，没有实际比对前不得声称像素级一致。

## 四、与用户模板源码隔离

如果希望 **绝不把 Everflow 私有排版算法泄露给客户**：
1. 浏览器端普通模式只使用公开排版器；任何下载到浏览器的 .cls/.typ/JS 都是公开的。
2. 私有模板模式必须放到服务端受保护的 XeLaTeX 环境，客户端只传题目数据；限制任意 TeX 指令、文件读写、编译时限。
3. 费用：普通模式可用浏览器算力免费；私有模式需要后端计算，不承诺无限并发零成本。

## 五、上线前检测

桌面 1440×900；平板 1024×768；手机 390×844 与 375×667，逐项测试：题目编辑、导入、无草稿/有草稿、模式选择、分页预览、PDF 下载、浏览器后退、断网、超大项目、字体加载、夜间主题。至少一轮真实浏览器截图检查，否则该版本仅属于“代码提交”，不能写“视觉验收通过”。
